NFSU2 Unique Performance integration

Open index.html. Expand Unique Performance under a garage slot to change per-car options.

The save checksum fix and Unique controls are implemented in js/unique-integrated.js.
The upstream js/app.bundle.min.js differs by only one bridge assignment exposing the currently loaded editor as window.__nfsu2Editor. No upstream download handler or checksum code was modified.

Weight Reduction and Engine were individually tested; the other labels remain inferred from category order. Backup saves before using.
