NFS Underground 2 Save Editor v1.0 by Starladdey (cybergod_)
=================================

A standalone, offline-capable save editor for Need for Speed: Underground 2.

GETTING STARTED
---------------

1. Extract all files from the ZIP archive into a folder.
2. Double-click index.html to launch the editor in your browser.
3. Open your NFS Underground 2 save file and edit your career data.
4. Save your changes and load the modified save in the game.

No installation or internet connection is required for basic editing.

OPEN ONLINE VERSION
-------------------

To access the latest version, double-click:

Open_Online_Editor.url

Or visit:
https://nfsu2.divon.eu/

SAVE FILE LOCATION
------------------

On Windows 10 / 11, press Win + R and enter:

%LOCALAPPDATA%\NFS Underground 2

BACK UP YOUR SAVES!
-------------------

Always create a backup of your original save files before editing them.

The developer is not responsible for lost or corrupted save data.

IMPORTANT NOTES
---------------

- Your save files are processed locally in your browser.
- Your save data is not uploaded to a server.
- Some features, such as online demo templates, may require an internet connection or a local HTTP server.
- Keep all files and folders in this archive together. Do not move or delete individual files.
